## 📌 Описание программы

**ByeDPI Manager Pro** — это удобная утилита с графическим интерфейсом (GUI), разработанная для управления консольными инструментами **ByeDPI (ciadpi)** и **ProxiFyre**. Программа предназначена для стабильного обхода DPI-блокировок интернет-провайдеров, восстановления доступа к **YouTube**, **Discord** и другим заблокированным ресурсам без использования сторонних тяжелых VPN-сервисов.

---

## 🔥 Основные возможности

- ⚡ **Умный подбор стратегий (DPI Tester):** Многопоточная проверка доступности сайтов для автоматического выбора идеальных аргументов запуска.
- 🔀 **3 режима маршрутизации трафика:**
  - **ProxiFyre:** Перенаправление трафика только конкретных `.exe` файлов (игры, браузеры, Discord).
  - **Системный прокси:** Включение обхода для всей системы Windows в один клик.
  - **Автономный SOCKS5:** Работа в режиме локального прокси-сервера.
- 📦 **Готовая сборка All-in-One:** Полный комплект всех зависимостей в одном архиве.
- 💻 **Полная совместимость:** Работает на Windows 7 SP1, Windows 10 и Windows 11 (x86 / x64).

## 📥 Как скачать и запустить

1. Перейдите в раздел **[Последние релизы (Releases)](https://github.com/YOUR_USERNAME/ByeDPI-Manager-Pro/releases/latest)**.
2. Скачайте файл **`ByeDPI.Manager.exe`** (или полный zip-архив `ByeDPI_Manager_Pro_All_In_One.zip`).
3. Запустите файл **`ByeDPI.Manager.exe`**.
4. В главном окне нажмите кнопку **«Подключить»**.
