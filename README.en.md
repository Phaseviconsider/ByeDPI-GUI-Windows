## 📌 Overview

**ByeDPI Manager Pro** is a lightweight GUI client designed to simplify managing **ByeDPI (ciadpi)** and **ProxiFyre** on Windows. It enables users to bypass DPI (Deep Packet Inspection) restrictions effortlessly without relying on full VPN services.
